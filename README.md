# TG Shop — бот для продажи товаров через Telegram Stars

MVP Telegram-магазина с админ-панелью, корзиной, оформлением заказа и оплатой через Telegram Stars.

## Возможности

- 📦 Каталог товаров с фото и ценами
- 🛒 Корзина (добавление, изменение количества, удаление)
- ✅ Оформление заказа: имя, телефон, адрес, комментарий, выбор доставки
- ⭐ Оплата через **Telegram Stars** (встроенные платежи Telegram)
- 📬 Заказы улетают в указанный канал с полной информацией
- 🛠 Админ-панель внутри бота: добавление/удаление товаров, просмотр заказов, назначение админов
- 💾 База данных SQLite (легко мигрировать на PostgreSQL)

## Быстрый старт

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Настройте `.env`
Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
ADMIN_IDS=123456789,987654321
CHANNEL_DEST=@your_channel_username
DATABASE_PATH=shop.db
```

- **BOT_TOKEN** — токен от [@BotFather](https://t.me/BotFather)
- **ADMIN_IDS** — ваш Telegram user_id (узнайте через [@userinfobot](https://t.me/userinfobot)), можно несколько через запятую
- **CHANNEL_DEST** — username канала (`@channelname`) или его ID (`-1001234567890`), куда будут приходить заказы. Бот должен быть администратором в канале.
- **DATABASE_PATH** — путь к файлу БД (по умолчанию `shop.db` рядом с ботом)

### 3. Запустите бота
```bash
python bot.py
```

## Команды бота

### Для покупателей
| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/catalog` | Открыть каталог |
| `/cart` | Открыть корзину |
| `/help` | Справка |
| `/cancel` | Отменить текущее действие |

### Для админов
| Команда | Описание |
|---------|----------|
| `/admin` | Меню админ-панели |
| `/add_product` | Добавить товар (пошаговый мастер) |
| `/products` | Список товаров с кнопками удаления |
| `/orders` | Последние 20 заказов |
| `/set_admin` | Назначить админа (ответьте на сообщение пользователя) |

## Добавление товаров (админ)

1. Напишите `/add_product`
2. Введите название
3. Введите цену в звёздах (целое число, например `150`)
4. Введите описание или `/skip`
5. Отправьте фото или `/skip`
6. Подтвердите добавление кнопкой ✅

## Доставка

Настроена в `config.py`:

```python
DELIVERY_METHODS = {
    "pickup": {"name": "Самовывоз", "cost": 0},
    "courier": {"name": "Курьер по городу", "cost": 50},
    "post": {"name": "Почта России / СДЭК", "cost": 100},
}
```

Меняйте под себя. Цена в ⭐.

## Оплата Telegram Stars

- Никаких провайдеров настраивать не нужно — это встроенные платежи Telegram
- `provider_token=""` в `send_invoice`
- Валюта `XTR` (Telegram Stars)
- Пользователь платит прямо в чате, средства зачисляются на ваш Telegram-аккаунт/бизнес-аккаунт

## Миграция на PostgreSQL

Для продакшена замените `database.py` на asyncpg/SQLAlchemy + PostgreSQL. Схема таблиц та же, только синтаксис запросов чуть отличается.

## Развёртывание

Рекомендую:
1. VPS с Ubuntu/Debian
2. systemd-юнит для автозапуска
3. nginx + Certbot для вебхука (опционально, polling работает нормально)
4. PostgreSQL вместо SQLite
